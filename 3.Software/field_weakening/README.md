# 245_b 弱磁研究

分支从 `main` 的 APP 245 创建，固件版本号仍为 245。保留 APP 245 的通信协议、OTA、校准与参数保存格式；现有 246 参数抽象分支独立保留。

## 配置

修改 `2.Firmware/ADM32F036_mc_app/user/field_weakening.c` 中的 `field_weakening_config` 结构体，重新编译后生效。这些是内部配置，不新增 CAN/Flash 参数。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `enabled` | `1` | 默认开启；Axis 参考实现默认关闭，本分支按要求开启 |
| `negative_id_limit_a` | `5.0` | 弱磁负 d 轴电流幅值上限，A |
| `voltage_threshold` | `0.4` | 限幅前 Vdq 相对于可用电压的利用率目标；研究值，Axis 默认 0.98 |
| `gain_a_s` | `400.0` | 利用率误差的积分增益，A/s；研究值，Axis 默认 200，不代表物理带宽 |
| `dq_current_limit_a` | `30.0` | d/q 总电流圆半径，A；采用 Axis 默认值，低于原 MC 的 35 A q 轴上限 |

参考来自本地 Axis 的 `components/axis/axis.c` 中 `field_weakening_step`、`allocate_dq_current` 和 `allocate_dq_voltage`。沿用原 MC 力矩/电流标定表，不增加磁链辨识或 PI 自动整定。

弱磁介入速度由上述利用率目标及积分增益调整。本版按研究要求将目标从 0.98 降到 0.4、增益从 200 提到 400 A/s；这是弱磁外层调节，不改变原 d/q 电流内环的 420/250 增益。

校准已经通过 `encoder_reverse` 统一了编码器方向，因此闭环计算电角度时直接使用该坐标，移除了原 main 在 `phase_reverse == 0` 时的第二次反向。校准扫描、LUT 与旧记录布局保留；该修复与 246 中的方向衔接修复一致，但不引入其电机参数抽象。

## 实际执行路径

1. 上电时按原库 `MOTOR_RATED_CUR` 和 PWM 时钟换算控制器系数。
2. `MotorControlISR` 在私有库 `CurrentLoop()` 之前生成最终 `pm_ref_id/pm_ref_iq`，避免后台 `RunCaseRun` 的赋值覆盖弱磁。原 `Id/Iq` 指令本身不累加弱磁。
3. 仅已校准、已使能、无故障的有感 FOC/MIT 运行允许弱磁；校准、停机、故障和启动检测期间复位积分。退出的第一拍恢复原始 d/q 给定，之后继续原来的给定路径。
4. 按上一拍限幅前电压利用率积分负 Id，范围为 `[-5 A, 0]`。Id 优先，Iq 使用同一 30 A 电流圆剩余空间，正负 Iq 对称处理。
5. 在 `CurrentLoop()` 之后、`VolVectCalation()` 之前记录原始 Vdq 幅值，并在负 Id 时优先保留 d 电压，q 电压使用剩余电压圆。可用电压直接使用原库 `pm_maxout_vol`，不是另设母线电压比例。
6. CAN 力矩统一按带符号的实测 q 轴电流估算。弱磁开关和 d 轴电流都不影响该换算，温升估算仍使用 d/q 电流幅值。

快环使用定点数，Q16 保留亚电流代码的积分增量，Q15 表示电压利用率。积分步长按硬件 `TBPRD` 和时钟计算，适应原 MC 的扩频 PWM，不把循环频率固定假设为 20 kHz。整数平方根复用原库 `qsqrt` 并校正近似误差，保证电流圆和电压圆不因近似值越界。

原私有库的 PI、后台参数计算和最终 SVPWM 继续使用。`field_weakening_status` 提供配置有效性、当前活动状态、最终 d/q 给定和上一拍限幅前利用率，供符号调试读取；利用率数值除以 32768 得到比例。

## 编译

在仓库根目录执行：

```powershell
python -B 3.Software/field_weakening/build_app.py
```

默认输出到 `2.Firmware/ADM32F036_mc_app/Debug/245_b/`，其中 `ADM32F036_mc_app_released_fw.bin` 是 48 KB APP OTA 包。需要 TI C2000 CGT 22.6.1.LTS；可用 `--compiler` 指定编译器目录。

编译器默认位置、编译/链接选项沿用现有 CCS 项目。构建会检查 COFF/BIN 一致性和 OTA 包 CRC，不访问硬件。

## 验证范围

离线验证覆盖 Axis 默认值对照、利用率积分与恢复、两种转向、电流/电压圆、模式和故障退出、后台赋值覆盖、力矩上报，以及旧 OTA/配置兼容。一次性测试程序和结果位于被 Git 忽略的 `Debug/field-weakening-research/`，不随研究源代码提交。

离线模型和编译成功不代表电机已完成弱磁运行验证。实机仍需确认负 Id、利用率、温升与转速变化；目前不包含对目标板的烧录或运行结论。

当前 TI 构建的程序到 OTA 尾部剩余 364 字节，RAM 程序区剩余 388 字节。新增弱磁算法位于 Flash，快环中新增计算没有浮点调用；中断最坏执行时间尚未上板测量。后续扩展需要同时复核容量与实际快环耗时。

在恒定 100% 利用率的离线给定测试中，负 Id 给定达到约 4.95 A 的时间由原参数的约 1.24 秒降到约 21 毫秒；这是给定生成速度，不是实测电流环阶跃结果。±1 Nm 的指令/反馈符号回放假设实测 Iq 已跟随给定，不能替代上板测量。
