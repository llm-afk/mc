**固件特性：**

```  bash

cd hxb_motion/bin/

```

**问题记录、分析：**

- **问题1：**狗上电会出现有几个关节通信挂了的现象（数据一直是0）

  - 4条腿的情况下重新上电10次验证关节通信失效是否是随机的
  - 只保留一条腿然后上电10次看
    - 1.正常
    - 2.关节2、4挂了    
  - 4条腿同时上电后，重复插拔一条腿的电源，看看每次上电是否都是通信正常
  - 只保留一条腿上电，然后依次上电其他腿
  - 只保留一条腿上电然后上电后重复插拔10次

- **问题2：**狗身上标零失效 --> **暂时用上位机标零解决这个问题往下推进**

  - 上位机标零逻辑是正常的

- **问题3：**motor_zero程序中的某些通道的id2的数据会显示id3的数据

  老驱动板是不会有这样的现象的，所以怀疑还是波特率设置的问题
